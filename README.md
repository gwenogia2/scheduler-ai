# Scheduler (Smart Study Schedule Generator)

## Problem Statement
Mahasiswa sering kali kesulitan membagi waktu antara jadwal kuliah, penumpukan tugas dengan *deadline* berdekatan, dan alokasi waktu belajar mandiri. Kurangnya manajemen waktu yang terstruktur sering berujung pada pengerjaan tugas di saat-saat terakhir (Sistem Kebut Semalam), hasil belajar yang tidak maksimal, hingga risiko mengalami *burnout*.

## Solution
**Scheduler** adalah **Full-Stack Web Application** cerdas berbasis **Laravel 13** dan **Laravel AI SDK**. Aplikasi ini membantu mahasiswa mengelola daftar tugas aktif dan memanfaatkan *Artificial Intelligence* untuk menyusun rekomendasi jadwal belajar harian (*time-blocking*) secara fleksibel, terstruktur, dan realistis.

## Tech Stack

* **Backend:** Laravel 13 (PHP)
* **Database:** PostgreSQL
* **AI Integration:** Laravel AI SDK
* **Testing:** PHPUnit
* **Frontend:** Blade Templating & Tailwind CSS
